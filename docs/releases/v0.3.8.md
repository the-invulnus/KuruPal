KuruPal 首个打包发布：桌面应用 **0.3.8**，Codex 插件 **0.1.4**。

- `KuruPal-0.3.8-macOS-arm64.zip`：macOS Apple Silicon 桌面应用，内含行情采集器，无需另外安装 AKShare。
- `KuruPal-Codex-Installer-0.1.4.zip`：Codex 插件安装目录，支持任务动作联动、设置大小和关注股票。需 Python 3 和支持插件的 Codex CLI。
- `SHA256SUMS.txt`：两个 ZIP 的校验和。
- `INSTALL.md`：供用户或 agent 使用的安装说明。

桌面 ZIP 解压后可将 `.app` 复制到 `~/Applications` 并启动，无需 DMG 或手动拖拽。插件 ZIP 解压到持久目录，再执行其中的 `sh install.command`；安装后刷新 Codex 会话，由用户审阅 Hook 信任。

当前仅提供 macOS arm64。应用使用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证；macOS 可能需要用户通过系统安全入口确认。此版本不提供 Intel Mac 或 Windows 包。

完整 agent 安装流程见 [README](https://github.com/the-invulnus/KuruPal/blob/v0.3.8/README.md)。
