# 桌宠素材制作清单

目前不需要制作素材即可运行：应用内置了一个 CSS 占位角色。以下是已经实现的动作协议；同一个包可以混用精灵图和 WebM。素材导入后保存在本机 IndexedDB，重启无需重新选择。

| 文件动作名 | 画面建议 | 默认触发 | 建议时长 | 循环 |
|---|---|---|---|---|
| idle | 呼吸、眨眼、轻晃 | 无事件时 | 2–4 秒 | 是 |
| happy | 微笑、小幅挥手 | 当日涨幅 ≥0.5%，低于大涨阈值 | 2–4 秒 | 否 |
| celebrate | 跳起、撒花、夸张欢呼 | 当日涨幅 ≥设定阈值，默认 3% | 3–5 秒 | 否 |
| sad | 垂头、委屈、抱膝 | 当日跌幅 ≥0.5%，低于大跌阈值 | 2–4 秒 | 否 |
| panic | 震惊、抖动、抱紧被子 | 当日跌幅 ≥设定阈值，默认 3% | 3–5 秒 | 否 |
| sleep | 打盹、呼吸、Z 字 | 非交易时段或用户暂停 | 3–5 秒 | 是 |
| offline | 发呆、疑惑、小问号 | 关注股票查询失败 | 2–4 秒 | 是 |
| hello | 挥手、看向用户 | 动作按钮；角色双击（原生拖动可能影响双击） | 2–3 秒 | 否 |

先做 idle + happy + sad + panic 四个也能用；缺少的动作自动回退 idle。不要把涨停/跌停画死在 celebrate/panic 中：目前判断的是用户设定的百分比阈值，并非交易所涨跌停状态。

## 统一画面要求

- 推荐画布 512×512，透明背景，角色脚底统一在约 y=440；四边留出 10% 空间。
- 所有动作使用同样的角色大小、朝向、脚底位置，切换才不会突然跳位。
- 气泡和股票数字由应用绘制，素材里不需要带文字。
- 默认显示约 230×230 CSS 像素，设置展开时约 190×230，保持正方形素材即可。
- 不需要制作行走方向图，本版没有沿屏幕边缘自动行走。

## 精灵图（推荐作为跨平台主素材）

透明 PNG / WebP；每格同尺寸，按从左到右、从上到下排列。推荐每格 256×256 或 512×512，12–24 FPS；单张图边长尽量 ≤4096，避免低配设备纹理问题。frames 可以小于完整网格格数，末尾空格不会播放。循环动作首尾自然衔接。

## WebM

无音轨、建议 24 FPS、512×512，编码 VP9 或 VP8。需要透明背景时导出带 alpha 的 WebM，并在目标系统实测。应用使用系统 WebView：WebM 编码支持和透明通道在不同 macOS / Windows / Linux 版本上可能不同，不能承诺全部一致；因此建议为关键动作保留透明精灵图版本。切换格式只要修改 manifest.json，不必修改代码。

播放错误会显示占位角色和错误提示。某些系统能够播放 WebM 但无法显示 alpha，这种情况不会触发解码错误，需要肉眼检查背景。应用不会下载浏览器或转码器来兜底。

## manifest.json 示例

将 manifest.json 和素材文件放在同一个目录；设置 → 导入素材包，同时多选 JSON 与所有素材文件。文件名大小写要匹配，当前不支持子目录或 ZIP 导入。整个包上限 100MB。

```json
{
  "name": "我的角色 v1",
  "actions": {
    "idle": {
      "type": "sprite", "src": "idle.png",
      "frameWidth": 256, "frameHeight": 256,
      "columns": 8, "frames": 32, "fps": 12, "loop": true
    },
    "celebrate": {
      "type": "video", "src": "celebrate.webm",
      "loop": false, "durationMs": 4000
    },
    "sad": {
      "type": "sprite", "src": "sad.png",
      "frameWidth": 256, "frameHeight": 256,
      "columns": 8, "frames": 32, "fps": 12,
      "loop": false, "durationMs": 3000
    }
  }
}
```

一次性动作到 durationMs 后返回待机（默认 4500ms，允许 500–30000ms）。idle、sleep、offline 保持到下一个状态。没有素材时使用内置占位角色，不影响行情功能。
