## 行情联动建议（2026-10-20，尚未实施）

建议以独立采集器→行情语义事件→现有动作队列的方式接入，避免让前端承担请求、异常处理或股票配置面板。自选股通过Agent/外部配置管理，先1～5只、交易时段60～120秒一次，避免全市场扫描。

AKShare的stock_bid_ask_em来自东方财富：[官方接口说明](https://github.com/akfamily/akshare/blob/main/docs/data/stock/stock.md)。同接口1.19.1的[2026-10-09问题报告](https://github.com/akfamily/akshare/issues/7439)显示低频请求也可能断连，维护者10月13日回复“数据源限制”。更换同源封装库不等于更换数据源；备用源须独立验证，不能先承诺稳定。

建议规则：首次仅建立基准；之后涨跌跨档、短时明显变化或由跌转涨时触发，同档不每次轮询都表演。上涨随机开心动作，大涨/明显反弹可候选捂嘴狂笑或新动作07，下跌随机失落动作。阈值和冷却是待定产品参数，不是投资信号。气泡明确股票、当日涨跌幅和行情时间，不把它称作持仓盈亏。

所有已入队动作仍完整播放、不打断；在入队前做行情去重和过期检查，防止排队结束后播陈旧报价。失败时只低频提示“行情暂不可用”，不触发下跌或失败颜艺；退避60/120/300/900秒，断线恢复后先重建基准。历史报价需标记过期，不能伪装成新行情。市场数据时间与本地采集时间分开；上游未提供时必须标记未知。休市/午休停止轮询，节假日需接交易日历，不只判断星期。

上线前建议跨3～5个交易日记录请求成功率、延迟、连续不可用时长、有效报价比例；同源切换和一次成功都不能证明可靠。2026-10-20本机一次默认代码000001采样约1.09秒返回ProxyError，仅说明本机当前链路未通，尚未测得稳定性指标。
